FormLayer playground

Server-rendered form scenarios for building and checking FormLayer features. Each page is plain HTML the way a CMS would render it. A mock backend at /api/forms/* answers like the TYPO3 sitepackage middleware.

  1. Contact: the baseline. Required fields, a radio group, a consent checkbox, a server-only rule and a form-level server error.
  2. Address: nested field names (billing[city]) and a whole fieldset that depends on a checkbox.
  3. Conditional fields: radio-driven fields, "other, please specify", and chained conditions.
  4. Repeatable group: add or remove participants, with per-row server errors.
  5. Cross-field rules: password confirmation, a date range, and "phone or backup email".
  6. Multistep: steps rendered by the server, a Back button, and server errors on step 2.
  7. Widgets: a checkbox group with limits, a combobox with groups and flags, a file upload.
  8. Server mode: data-server-validation="server", where every field is checked by the server and client rules are skipped.

Run npm run playground:check to record what the current library supports in playground/CAPABILITIES.md.
