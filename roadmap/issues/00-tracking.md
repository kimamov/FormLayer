# Roadmap: 0.4 bugfix release and FormLayer v2 (tracking)

Labels: `enhancement`

Tracking issue for the plan in [`ROADMAP.md`](../../ROADMAP.md).

**Goal for v2:** a small base library that is easy to extend with custom markup, field types, events and validators. A CMS integrator with a little TypeScript experience should be able to build something like a country combobox with flags and grouped options without touching keyboard handling or ARIA code.

## Guiding decisions

1. The server-rendered markup stays the source of truth. JS enhances markup that already exists.
2. Mirrored validators (`data-validate`) stay the default.
3. Server-authoritative validation is **opt-in**: the core owns the mechanism, adapters (TYPO3 first) own the transport.
4. One way to write a field (`defineField()`), one way to configure one (options at registration). Subclassing is not public API.
5. No feature soup. See "Deliberately not doing" in the roadmap.
